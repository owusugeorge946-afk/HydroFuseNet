# Public-release checklist

- [ ] Add the final GitHub repository URL to `CITATION.cff`.
- [ ] Add all manuscript co-authors to `CITATION.cff`.
- [ ] Add the manuscript DOI when available.
- [ ] Confirm the exact uncertainty formula used in the final code.
- [ ] Check all CSV values against the final accepted manuscript.
- [ ] Add source-code scripts/notebooks if they are to be released.
- [ ] Add model checkpoints only if storage and licensing permit.
- [ ] Choose repository and data licenses.
- [ ] Confirm that no restricted/raw third-party imagery is included.
- [ ] Create a tagged release (recommended: `v1.0.0`) after validation.
